# MERN App Client

This is the client-side of the MERN (MongoDB, Express, React, Node.js) application. The frontend is built using HTML, CSS, and JavaScript.

## Project Structure

```
client
├── public
│   ├── index.html      # Main HTML file
│   ├── styles.css      # CSS styles for the application
│   └── script.js       # JavaScript code for handling user interactions
```

## Getting Started

To run the client-side application, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the client directory**:
   ```
   cd mern-app/client
   ```

3. **Open the `index.html` file** in your browser to view the application.

## Features

- User interface for interacting with the backend API.
- Responsive design using CSS.
- JavaScript for dynamic content and API calls.
